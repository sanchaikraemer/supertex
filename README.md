# Acompanhamento da Concreteira — Supertex

Relatório automático das concretagens a partir da conversa do grupo do WhatsApp.

## Como usar
1. No WhatsApp, abra o grupo da obra → ⋮ → Mais → **Exportar conversa** → Sem mídia.
2. Abra o `index.html` no navegador.
3. Arraste o arquivo exportado (.zip ou .txt) para o quadro da página.

## O que aparece
- **Relatório:** um resumo pronto para copiar e mandar.
- **Por dia:** cargas, m³, horários e espera de cada dia.
- **Cargas:** cada caminhão com a nota fiscal, o BT, a hora do pedido, a hora da saída e a espera.
- **Ocorrências:** chuva, cancelamentos, reclamações, troca de usina, e os áudios e fotos que precisam ser vistos no celular.
- **Notas e caminhões:** a lista das notas fiscais para conferir com a fatura.

A conversa não sai do seu computador: a página lê o arquivo ali mesmo.
